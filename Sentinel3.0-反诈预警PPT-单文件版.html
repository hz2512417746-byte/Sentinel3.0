Algorithms · 核心算法

两个算法，全部手写

WL图核 · 结构指纹
手工 WL 图核

不调用任何第三方 NLP / 图算法库，从度分桶到相似度全链路 Java 手写。

  • 度分桶 L0–L4 构建拓扑指纹
  • 余弦相似度完成子图比对
  • 1000 节点子图匹配 <10ms
  • 内存占用 <500MB，可长期驻留
LCS弹性序列 · 剧本识别
弹性 LCS

在经典最长公共子序列上引入时间衰减与跳过惩罚，容忍诈骗剧本的噪声与变体。

  • 动态规划 + 时间衰减因子
  • 跳过惩罚容忍插入噪声
  • 剧本召回率 50% → 67%
  • 纯 Java 实现，零外部依赖
