# Sentinel 3.0 — 融合增量特征与规则引擎的 DPI 实时反诈预警系统

## 技术栈

```
数据采集层: 日志模拟器 → Kafka(dpi_logs)
流处理层: Flink 1.18 (ZengKuai 增量特征计算) → Kafka(dpi_enriched)
应用服务层: Spring Boot 3.2 (规则引擎22条 + SMILE 逻辑回归ML) → 三态决策(block/warn/allow)
存储层: MySQL 8.0 (持久化) + Redis 3.0 (封号/拦截名单缓存)
推送层: 原生 WebSocket + REST API
前端层: Vue3 + Pinia + Element Plus + ECharts
```

## 实际模块

| 模块 | 路径 | 说明 |
|------|------|------|
| 模拟器 | simulator/ | 银行 DPI 日志生成器，80条/s，200用户，3%欺诈率 |
| Flink 作业 | flink-job/ | Flink RichMapFunction 嵌入 ZengKuaiEngine，17维特征实时注入 |
| 后端 | backend/ | Spring Boot 3.2，消费 dpi_enriched，规则+ML评分，WebSocket推送 |
| 前端 | frontend/ | Vue3 8页仪表盘，原生WebSocket+HTTP双通道 |
| Kafka 配置 | kafka-config/ | Topic 创建脚本 |

## 数据流（实际运行）

```
模拟器(80条/s) → Kafka(dpi_logs, 4分区)
       ↓
Flink 1.18 (LocalEnv, parallelism=1)
  └─ ZengKuaiEnrichFunction (RichMapFunction)
       └─ ZengKuaiEngine: 时间分桶(15m/60m/1440m) → 17维特征
       ↓
Kafka(dpi_enriched, 4分区, 带 features 键)
       ↓
Spring Boot 3.2
  ├─ Kafka Consumer (dpi-backend-enriched)
  ├─ 规则引擎: 22条银行业务规则 (RuleSeeder)
  ├─ ML评分: SMILE 逻辑回归，17维特征 → P(欺诈)
  ├─ 决策融合: riskScore = 0.4×规则 + 0.6×ML
  └─ 三态决策: block(≥0.65) / warn(≥0.45) / allow(<0.45)
       ├─ MySQL: log_events + alerts + block_records (批量500ms写入)
       ├─ Redis: banned_users / intercepted_users (双向同步)
       └─ 原生 WebSocket: /ws/logs (type=log|alert 实时推送)
       ↓
Vue3 前端 (8页)
  ├─ WebSocket 实时 (1秒批量渲染) + HTTP 轮询 (5秒兜底)
  ├─ 三态决策行背景色: block红 / warn橙 / allow无色
  └─ 搜索/过滤/翻页: Logs, Alerts, History 完整
```

## 决策体系

| 决策 | 阈值 | 标签 | 动作 |
|------|------|------|------|
| block (阻断) | riskScore ≥ 0.65 | 红色 | 自动拦截 + 触发告警 |
| warn (预警) | riskScore ≥ 0.45 | 橙色 | 触发告警 |
| allow (放行) | riskScore < 0.45 | 无色 | 正常 |

自动封禁: 月累计 ≥ 50 次告警 → 写入 block_records + Redis 封号名单

## ML 模型

- 算法: 逻辑回归 (L2 正则化, λ=0.1)
- 实现: SMILE 2.6.0 (纯 Java, ~2MB)
- 特征: 17维 (ZengKuaiEngine 输出)
- 训练集: 20000 条 (模拟器生成, 欺诈率 3.2%)
- 性能: Accuracy 98.9%, AUC 0.84
- 部署: 序列化到 resources/ml_model.ser，Spring 启动时加载
- 回退: 模型文件缺失时自动切换到手写加权评分
